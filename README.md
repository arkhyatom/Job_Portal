# Job Portal Web Application

A job portal web application built using Python and Django that connects job seekers with employers.

## Features

- Candidate registration and login
- Employer registration and login
- Browse and search job listings
- View job details
- Apply for jobs
- View submitted applications
- Employers can post and manage job listings
- Employers can view applicants
- Company logos and responsive styling

## Technologies Used

- Python
- Django
- SQLite3
- HTML
- CSS
- Git and GitHub

## Installation and Setup

1. Clone the repository:

   `git clone https://github.com/arkhyatom/Job_Portal.git`

2. Open the project folder:

   `cd Job_Portal`

3. Create and activate a virtual environment:

   `python3 -m venv env`

   On macOS:

   `source env/bin/activate`

4. Install the dependencies:

   `pip install -r requirements.txt`

5. Apply database migrations:

   `python manage.py migrate`

6. Start the development server:

   `python manage.py runserver`

7. Open `http://127.0.0.1:8000/` in your browser.
